# vic3trendkeeper

让维多利亚 3 的历史图表在**切换国家后**和**观察者模式下**保持完整。测试版本：Victoria 3 **1.14.5**。

> English: keeps Victoria 3 history charts complete after switching countries and in observer mode. Two parts: a runtime memory helper (`trend_keeper`) that fixes the engine, and a pure Steam-workshop-compatible mod (`full_history_charts`).

## 两个部分

| | Trend Keeper | Full History Charts |
|---|---|---|
| 类型 | 外部助手，运行时修改游戏内存 | 纯 mod，放进播放集即可 |
| 能否上创意工坊 | 不能 | 能 |
| 修复原版图表 | **能**：切换国家不再清空，所有国家记录人口，曲线延长到 100 年 | 不能，另做一套图表 |
| 兼容图表类 mod | 天然兼容（修的是数据源，GDP Plotline Plus、GORA UI+ 等一起变完整） | 并存，不覆盖原版界面 |
| 数据精度 | 原版每周一个点 | 每年 1 月 1 日一个点 |
| 额外功能 | 游戏内按钮和快捷键开关；旧存档历史恢复工具 | 日志里的 5 个开关；14 项指标；CSV 导出；旧存档导入 |

两者可以同时使用，互不冲突。

## 快速开始

**Trend Keeper**（Windows，需要 Python 3）
1. 双击 `trend_keeper/tools/启动 Trend Keeper.bat`，保持"游戏启动后自动应用"为勾选。
2. 启动游戏。助手会自动连接并打补丁，窗口里可以随时开关每一项。
3. 想让扩容类补丁对已有存档生效，需要打补丁后重新读档。
4. 版本不匹配时助手只读不改。先运行 `python trend_keeper/tools/trend_keeper.py selftest` 自检。

**Full History Charts**
1. 把 `full_history_charts` 文件夹放进 `文档/Paradox Interactive/Victoria 3/mod/`。
2. 在启动器的播放集里添加它。
3. 进游戏后，在左侧日志里找到"历史图表"条目；右下角圆形按钮或 Ctrl+Shift+G 打开图表。

## 资源占用预测

标注"实测"的是在 1943–1945 年的存档上测的；标注"估算"的是按代码里的容量和采样频率推算的，**没有在游戏里单独测过**。

### Trend Keeper

| 补丁（默认） | CPU | 内存 | 存档体积 | 依据 |
|---|---|---|---|---|
| 切换国家不清空曲线（开） | 无额外开销 | 被切走国家的曲线不再释放；估算远小于下面两项 | 无变化 | 只是跳过清空，没有新增运算 |
| 所有国家记录人口（开） | 实测：测不出差异 | 每个国家多几条曲线，量小 | 实测：每游戏年约 +0.2 MB | 8 轮开关交替测试，噪声约 ±10% |
| 延长存档曲线（开） | 无（只改保留时长，不改写入次数） | 约 +48 MB | 每游戏年约 +0.5 MB，整局约 +50 MB | 曲线数量乘容量计算；容量在对象创建时分配，只对改后读档的对象生效 |
| 延长预算曲线（开） | 无 | 约 +135 MB（读档后立即分配） | 不进存档 | 同上 |
| 单个 pop 曲线（**关**） | 有，随游戏进程增加 | 每游戏年约 +225 MB，持续增长 | 不进存档 | 默认关闭，不建议长期开 |

- **磁盘**：助手本身是几个 Python 脚本，合计约 100 KB；日志在 `trend_keeper.log`，超过 1 MB 自动轮转。
- **存档处理工具**：处理 1945 年的存档（扩容 2808 条曲线、补回约 35 万个历史采样）后，309.0 MB 变为 310.5 MB（+0.5%）。
- **整体判断（估算）**：默认配置下，内存约增加 180 MB，存档每游戏年增加约 0.7 MB。到 100 年局末，存档约 +70 MB，这是上限量级。

### Full History Charts

| 项目 | 数值 | 依据 |
|---|---|---|
| CPU | 估算：可忽略 | 每年记录一次（约 110 个国家 × 14 项）；日志条目每月只做一次是否已有的检查；图表窗口关闭时不刷新，打开时只刷新当前页约 150 个单元格 |
| 内存 | 估算：约十几 MB 量级 | 约 15.4 万个国家变量（100 年满载），数量级与存档增量接近 |
| 存档体积 | 实测：每个数值变量约 91 字节；每游戏年约 +0.15 MB，100 年约 +15 MB（约 +5%） | 在一个导入了 1910–1945 年历史的存档上，增加 1.2 MB |
| 磁盘（mod 本身） | 约 1.6 MB（GUI 文件占 1.28 MB） | 文件大小 |

### 怎么自己测

- 助手窗口点"性能测试 60s"，或运行 `python trend_keeper/tools/trend_keeper.py compare 60 fix_pop_stats`，会交替开关补丁并比较 CPU 和游戏速度。
- 存档体积：对比启用前后同一天的自动存档大小。

## 限制

- Trend Keeper 的补丁地址只适用于 1.14.5（`victoria3.exe` 97,774,200 字节）。游戏更新后要重新适配，在此之前助手会因签名不匹配而自动进入只读模式。
- 预算、州、建筑、市场价格这几类曲线原版就不写进存档，读档后从读档当天重新开始。
- 补丁生效之前从来没被记录过的数据找不回来；被清空但旧存档里还留着的部分，可以用 `恢复存档历史.bat` 补回。
- 纯 mod 的日志条目只出现在玩家国家上；观察者模式下没有玩家国家，条目和开关不会出现，但记录和图表照常工作。

## 目录

| 目录 | 内容 |
|---|---|
| `trend_keeper/` | 助手（`tools/trend_keeper.py`）、存档历史恢复（`tools/trend_restore.py`）、游戏内按钮 mod 和详细说明 |
| `full_history_charts/` | 纯 mod 本体 |
| `fhc_tools/` | 纯 mod 的生成器、检查脚本、存档导入和 CSV 导出工具 |

## 说明

- Trend Keeper 只修改运行中的游戏内存，不改动 `victoria3.exe`；关掉助手或重启游戏即恢复原样。改动的都是"仅供界面展示"的趋势数据，不参与游戏逻辑和联机同步。
- 这是非官方项目，与 Paradox Interactive 无关。仓库还没有选定开源许可证，在选定之前，默认保留所有权利。
