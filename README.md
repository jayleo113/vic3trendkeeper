# Victoria 3 历史图表工具

让维多利亚 3 的历史图表在切换国家、观察者模式下也保持完整。测试版本：Victoria 3 1.14.5。

| 目录 | 说明 |
|---|---|
| `trend_keeper/` | 运行时内存补丁助手：不再在切换国家时清空曲线、修复人口曲线只记 ID%7 国家的 bug、延长曲线容量。不能上传创意工坊，本机手动运行。 |
| `full_history_charts/` | 纯 mod（创意工坊可用）：每年记录各国数据，自带历史图表面板，日志里带开关。 |
| `fhc_tools/` | 纯 mod 的生成器、检查脚本、存档导入和 CSV 导出工具。 |

详细说明见各目录的 `README.md`。

## 注意
- Trend Keeper 只修改运行中的游戏内存，不改动 `victoria3.exe`；补丁地址只适用于 1.14.5，游戏更新后需要重新适配（先运行 `python trend_keeper.py selftest`）。
- 存档文件和导出数据不在仓库里。
