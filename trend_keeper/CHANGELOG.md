# Changelog

## 4.0.0

**新补丁**
- `track_all_states`（默认开）：修复观察者模式下，除被跟踪国家之外，其它国家的州和建筑曲线停止更新的问题。每周的趋势更新循环对每个州先查所属国家是否被跟踪，不是就跳过；补丁只改这一个两字节的条件跳转。
- `cap_investment`（默认关，实验性）：限制自主投资每国每周的落地次数，按该国潜在建筑数动态计算上限；预算和统计可在游戏运行中在线调整。会改变模拟结果，联机必须所有人同样开启。

**界面**
- 全新的深色界面：左侧导航，右侧一行一项带开关，统一字体，高 DPI 清晰，说明文字自适应换行。
- 系统托盘图标和同风格的深色弹出菜单（状态、打开窗口、默认修复开关、限制自主投资开关、热点采样、退出）；关闭窗口默认缩到托盘；可选"启动时只显示托盘图标"。
- "当前存档"：显示补丁在这个存档里生效的游戏日期范围（记录写入 `trend_keeper_coverage.json`）。
- 桌面快捷方式（折线图图标）：`python trend_keeper.py shortcut`。

**诊断工具**
- `profile`：只读热点采样，按线程统计各函数占比，含自主投资相关函数的调用者归因。
- `invest`：查看和在线修改 `cap_investment` 的参数与统计。
- `coverage`、`version` 命令。

**健壮性**
- `selftest` 自动找 victoria3.exe（`VIC3_EXE`、运行中的游戏、Steam 库），不再写死路径；恢复工具的历史/输出目录改为相对仓库，可用 `TK_HISTORY_DIR`、`TK_OUT_DIR` 覆盖。
- 代码洞分配不再重复发放；助手自己申请的可执行内存块在游戏进程里创建，失败时补丁保持关闭。
- 新增离线测试（时钟换算、覆盖日期逻辑、补丁定位与原始字节、代码洞/补丁位点互不重叠、生成代码的反汇编校验）。
- 窗口始终以正常状态打开。
