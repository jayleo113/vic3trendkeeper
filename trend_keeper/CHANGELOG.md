# Changelog

## 4.1.0 · 适配 Victoria 3 1.15.0

游戏更新到 1.15.0（`victoria3.exe` 99,988,600 字节）后，7 个补丁里 `keep_history`、`fix_pop_stats`、`extend_saved`、`track_pops` 的特征码失效。重新定位后全部恢复，并且 1.14.5 仍然支持。

**怎么适配的**
- 1.15 里国家结构体的一部分字段整体后移（例如国家曲线 `+0xB0`，自主投资 AI 对象 `+0x28`），代码形状没变。所以特征码里写死的结构体偏移改成通配，或者按"形状"定位：
  - `keep_history`：找"四次 `lea rcx,[r14+D]; call CTrend::Clear`，偏移间隔 0x38/0xA8/0xE0、目标相同"。
  - `extend_saved`：1.14.5 的精确特征码失败时，改成按 `Init(曲线, 采样间隔, 时长)` 的参数形状找 9 处（国家构造函数一对、变为被跟踪/不被跟踪各一对、利益集团影响力和激进/忠诚）。
  - `cap_investment`：不再写死潜在建筑数在 AI 对象的 `+0x21c`，而是从代码里读（1.14.5 是 `0x21c`，1.15.0 是 `0x244`）。
- 新增游戏版本显示（从启动器的 `launcher-settings.json` 读取），`selftest`、`status`、窗口左下角都会显示。
- 测试接受所有已验证的版本。

**1.15.0 的对应位置（映像基址 `0x140000000`）**

| 内容 | 1.14.5 | 1.15.0 |
|---|---|---|
| ClearCountryTrends 函数 | `0x1407FB1E0` | `0x141456750` |
| 其中第一处清空曲线（keep_history 补丁点） | `0x1407FB30E` | `0x14145687B` |
| 其中"仅有的非曲线写入" `mov byte [r14+X],0` | `X = 0x2408` | `X = 0x24B8` |
| `IsTrendUpdateDay`（人口曲线的 ID%7 判断） | `0x140C7B9C0` | `0x14090E700`（仍是同一个 `ID%7` 逻辑，在 `0x140CB2EA0`） |
| `RecalcCountryPopStatistics` 里的调用点 | `0x140C7736A` | `0x14090A06A` |
| 州循环里"被跟踪才更新"的跳转（track_all_states） | `0x1414943BF` | `0x140CAC3FF` |
| 自主投资落地次数（cap_investment 补丁点） | `0x140F7746E` | `0x1409AA91E` |
| AI 对象里的潜在建筑数 | `+0x21C` | `+0x244` |

**在 1.15.0 上的验证**
- `selftest` 全部通过；16 个离线测试通过；全部补丁的原始字节核对一致。
- 在运行中的 1.15.0 游戏（1836 年开局）里依次打开 `keep_history`、`fix_pop_stats`、`track_all_states`、`extend_budget`、`extend_saved`：游戏未崩溃，日期正常推进，错误日志里没有曲线相关报错。
- `cap_investment` 统计模式下读到潜在建筑数 110，和 1.14.5 的量级一致，说明新偏移 `0x244` 正确。
- **没验证**：这些补丁在 1.15.0 里的长期效果（图表是否真的完整、内存长期增长）还需要玩一段时间确认。

## 4.0.0

**新补丁**
- `track_all_states`（默认开）：修复观察者模式下，除被跟踪国家之外，其它国家的州和建筑曲线停止更新的问题。每周的趋势更新循环对每个州先查所属国家是否被跟踪，不是就跳过；补丁只改这一个两字节的条件跳转。
- `cap_investment`（默认关，实验性）：限制自主投资每国每周的落地次数，按该国潜在建筑数动态计算上限；预算和统计可在游戏运行中在线调整。会改变模拟结果，联机必须所有人同样开启。

**界面**
- 全新的深色界面：左侧导航，右侧一行一项带开关，统一字体，高 DPI 清晰，说明文字自适应换行。
- 系统托盘图标和同风格的深色弹出菜单（状态、打开窗口、默认修复开关、限制自主投资开关、热点采样、退出）；关闭窗口默认缩到托盘；可选"启动时只显示托盘图标"。
- "当前存档"：显示补丁在这个存档里生效的游戏日期范围（记录写入 `trend_keeper_coverage.json`）。
- 桌面快捷方式（折线图图标）：`python trend_keeper.py shortcut`。

**诊断工具**
- `profile`：只读热点采样，按线程统计各函数占比，含自主投资相关函数的调用者归因。
- `invest`：查看和在线修改 `cap_investment` 的参数与统计。
- `coverage`、`version` 命令。

**健壮性**
- `selftest` 自动找 victoria3.exe（`VIC3_EXE`、运行中的游戏、Steam 库），不再写死路径；恢复工具的历史/输出目录改为相对仓库，可用 `TK_HISTORY_DIR`、`TK_OUT_DIR` 覆盖。
- 代码洞分配不再重复发放；助手自己申请的可执行内存块在游戏进程里创建，失败时补丁保持关闭。
- 新增离线测试（时钟换算、覆盖日期逻辑、补丁定位与原始字节、代码洞/补丁位点互不重叠、生成代码的反汇编校验）。
- 窗口始终以正常状态打开。
