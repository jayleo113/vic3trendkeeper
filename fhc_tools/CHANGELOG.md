# Full History Charts 更新日志

## 1.5.0
- 在游戏左侧的**日志（Journal）**里新增条目"全时间历史图表"，带 5 个开关，随时可点，不需要重启：暂停记录 / 恢复记录 / 立即记录一次 / 隐藏图表按钮 / 显示图表按钮。
- 暂停记录只停止新的记录（含新成立国家的记录），已有数据保留。
- 日志条目会自动出现在每个玩家国家上：开局时、之后每月检查一次。切换扮演国家后，最迟下个月出现。
- 新增打包版 zip，直接解压即可作为本地 mod 使用，也可以直接上传创意工坊。

## 1.3.0
- 横轴改为所有页面共用的**线性时间轴**：某一年没有数据时留空，不再挤到一起；各指标页之间同一年份对齐。
- 年份刻度改为全页共用一行，刻度单元格从 2100 个减到 150 个。
- 新工具 `export_csv.py` 及 `导出CSV.bat`：把存档中所有国家的年度数据导出为 CSV，包括长表和每个指标一张宽表。
- 新增创意工坊商店页介绍 `workshop_description.txt`（中英双语）。

## 1.2.0
- 柱子自动铺满图宽，最宽 24 像素。
- 顶部摘要新增"较上年"和"自首次记录"；分母不大于 0 时隐藏。
- "跟随打开的国家"在没有可跟随的国家时自动回退到本国视图，不再出现空白窗口。
- 选中的标签页和视图改用彩色线标记，按钮不再变灰。
- 修复：`#weak` 不是游戏定义过的文本格式，改为 `#grey`。
- 启动按钮移到右下角。
- 新工具 `import_history.py` 及 `导入历史到存档.bat`：把游戏自带的历史曲线导入已有存档。

## 1.1.0
- 年份和槽位判断改为二分查找。
- 每根柱子只用一个控件，公共属性放进 `template`。
- 新增纵轴、网格线、年份刻度，以及首值、最高值、最新值。
- 新增"本国"和"跟随打开的国家"两种视图、快捷键 Ctrl+Shift+G、ESC 关闭。

## 1.0.0
- 首个版本：每年为每个国家记录 14 项指标，并在 scripted widget 窗口中显示。
