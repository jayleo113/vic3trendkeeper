# Full History Charts · 全时间历史图表（纯 mod 版，v1.3）

> 各版本的变化见 `CHANGELOG.md`；创意工坊商店页介绍（中英双语 BBCode）见 `workshop_description.txt`。

- mod 本体：`G:\Victoria3Mods\full_history_charts`。C 盘 mod 目录里只有指向这里的 junction，加一个 `.mod` 描述文件。
- 安装：在启动器的播放集里勾选 **Full History Charts - 全时间历史图表**。不需要外部程序，不修改 exe。
- 本目录（`fhc_tools`）放的是生成器、检查工具和存档导入工具，不会随 mod 上传。

## 原理

- 开局时、在已有存档中启用后的第一个月度事件时、以及每年 1 月 1 日，脚本给**每个存在的国家**记录一组国家变量：`fhc_<指标>_<年份序号>`，另加首值、最新值、上一年值和最高值。最多保存 150 年。
- 这些变量会随存档保存，不受切换国家、改 tag 影响；AI 国家同样记录，观察者模式下所有国家都有全时间线。
- 界面通过官方的 `gui/scripted_widgets` 机制创建，不覆盖任何原版 GUI 文件。只有快捷键文件是整体覆盖的。

## 界面与控制

- **打开方式**：
  - 屏幕右下方的圆形 GDP 按钮（可拖动）；
  - 快捷键 **Ctrl+Shift+G**；
  - **ESC** 或右上角的 × 关闭。窗口可拖动。
- **视图**：
  - "本国 / 被观察国"；
  - "跟随打开的国家"：在地图上点任意国家即可切换。还没点开过任何国家时，自动显示本国，不会出现空白窗口。
- **当前选择的标记方式**：当前视图和当前指标页，都在按钮下方显示一条彩色线，按钮本身始终可点。
- **14 个指标**：GDP、人口、人均 GDP、声望、识字率、生活水平、每周收入、国库、债务、陆军、海军、激进比例、忠诚比例、恶名。
- **图表**：
  - 每年一格，**所有指标页共用一条线性时间轴**：某一年没有数据时留空，同一年份在各页的位置相同；
  - 柱子自动铺满图宽：年数少时变宽（最宽 24 像素），年数多时自动变窄；
  - 年份刻度全页共用一行，与柱子逐格对齐，每 10 年一个；
  - 纵轴标出最高值、一半和 0，配网格线；
  - 悬停柱子显示年份和数值。
- **摘要**：
  - 第一行：首值、最高值、最新值；
  - 第二行：较上年变化、自首次记录以来的变化。分母不大于 0 时自动隐藏，不会出现除以零的数字。

## 导出到 Excel / MATLAB：`导出CSV.bat`

- 把最新存档里所有国家的年度数据导出到 `G:\Victoria3Mods\exports\`。文件用 UTF-8 BOM 编码，Excel 可以直接打开。
- 导出内容：
  - `<存档>_long.csv`：长表，列为国家 ID、tag、指标、年份、数值、来源；
  - `<存档>_<指标>.csv`：每个指标一张宽表，行是年份，列是国家。
- 数据来源：优先用 mod 记录的变量；没有时，从游戏自带的每周曲线换算出年度值（规则同导入工具）。所以没装 mod 的存档也能导出。
- 实测：
  - 导入后的本局存档：12233 行，用时约 3 秒；
  - 最新的原版自动存档（1950.7.1）：15648 行，全部来自游戏曲线。

## 旧存档：导入游戏自带的历史（`导入历史到存档.bat`）

- mod 只能从启用那一刻开始记录。但游戏自己保存了每周的 GDP、声望、识字率、生活水平、人口曲线，以及最近 10 年的激进/忠诚人口。
- 双击 `导入历史到存档.bat`：
  1. 取最新的明文存档，从这些曲线中每年取最接近 1 月 1 日的样本，写成 mod 使用的变量；
  2. 输出新存档 `<名字>_fhc.v3` 到 `G:\Victoria3Mods\restored\`，并复制到存档目录。原存档不会被修改。
- 规则：
  - 连续 52 周以上完全相同的数值，是引擎在国家未被记录期间填充的，视为缺失，不画假柱子；
  - mod 已经记录的年份以 mod 为准；导入的历史起始更早时，自动给已有数据重新编号；
  - 每周收入、国库、债务、军队、恶名这几项游戏没有保存历史，只能从启用 mod 起记录。
- 你这局已经生成好一份：`G:\Victoria3Mods\restored\autosave_tk_fhc.v3`。它基于之前修复过的存档，包含 108 个国家、1910–1945 年共 12233 个年度样本。
  - 抽查 CHI 的 GDP，1938–1944 年的值与原始曲线一致；
  - 对这份存档再导入一次，新增 0 个样本，结果完全一致。

## 性能与代价

| 项目 | 做法 / 数值 |
|---|---|
| 年份与槽位判断 | 二分查找，约 11 + 8 次比较 |
| 记录 | 每年一次，约 110 国 × 14 项，可以忽略 |
| 界面刷新 | 窗口关闭时不刷新；打开时只刷新当前视图的当前页（约 150 个单元格和柱子）加一行共用刻度；悬停时才计算提示文字 |
| 存档 | 每个数值变量约 91 字节（实测）；每年约 +0.15 MB，100 年约 +15 MB（约 +5%）。导入 1910–1945 年历史后，本局存档增加 1.2 MB |
| GUI 文件 | 1.28 MB；年份刻度单元格从 2100 个减到 150 个 |

## 已知取舍

- 每年一个点，最多 150 年；超过后保留最早的 150 年。
- 快捷键需要整体覆盖 `gui/shortcuts.shortcuts`。如果游戏更新后原版新增了快捷键，需要重新运行 `generate.py` 同步；如果其他 mod 也覆盖这个文件，快捷键可能失效，但按钮不受影响。
- 导入工具只支持 `-debug_mode` 下保存的明文存档。
